# 完整开源项目源码

包含 ERPNext 与 InvoicePlane 的完整上游源码快照，保留原始目录、许可证和项目文档；不包含 Git 历史及安装后生成的依赖。具体提交版本见 UPSTREAM_SOURCES.json。

GitHub 网页上传单文件限制为 25 MiB，因此采用无损 tar.xz 归档。下载后在终端执行：

```sh
mkdir -p projects
tar -xJf frappe--erpnext.tar.xz -C projects
tar -xJf InvoicePlane--InvoicePlane.tar.xz -C projects
```

解压后分别按各项目 README 的官方安装说明配置环境。源码收录不代表已部署或验证可运行。
